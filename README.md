# Speech Quest Adventure

An Android adventure game built in **Unity (C#)** as my BS Computer Science thesis at Western Mindanao State University.

🏆 **Best Paper Presenter (1st Place)**, College of Computing Studies Annual Thesis Colloquium (2023)

## Tech stack

- **Engine:** Unity 2021.3.8f1 LTS
- **Language:** C#
- **Backend:** Firebase Authentication and Firebase Realtime Database
- **Platform:** Android (APK build)

## Try the game

1. Download `Speech Quest Adventure.apk` from this repository.
2. Install it on an Android device. You may need to allow installs from unknown sources.

## Open the project in Unity

Full steps are in [Installation and Guide Steps.pdf](./Installation%20and%20Guide%20Steps.pdf). In short:

1. Install Unity Hub and activate a free personal license.
2. Install Unity Editor 2021.3.8f1 LTS with the Android Build Support modules (Android SDK & NDK Tools, OpenJDK) and Visual Studio.
3. Download and extract the project folder (link in the guide), then open it from Unity Hub.

> **Note:** The game connects to a Firebase project on a personal account. To run it against your own backend, create a Firebase project, enable Authentication and Realtime Database, and update the project's Firebase configuration.
